# Milestone Registry

Milestones are implementation contracts. Active milestones describe intended
changes. Completed milestones are historical records.

## Lifecycle

An active milestone lives at:

```text
docs/milestones/active/m<nn>-<slug>/milestone.md
docs/milestones/active/m<nn>-<slug>/scratchpad.md
```

Use the [milestone template](template.md) and the next unused number. When work
ends, fill the outcome, preserve unchecked validation, add a historical banner,
move the directory to `completed`, and update this registry.
